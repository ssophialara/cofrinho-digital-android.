# Cofrinho Digital

**Cofrinho Digital** é um aplicativo Android intuitivo desenvolvido em **Jetpack Compose** com a finalidade de ajudar os usuários a gerenciar suas economias e acompanhar metas financeiras de forma simples e visual.

---

## Funcionalidades Principais

- **Acompanhamento de Saldo e Meta**: Exibição do valor guardado e da meta estipulada em reais.
- **Barra de Progresso Dinâmica**: Indicador visual e percentual do andamento em direção ao objetivo.
- **Depósitos Rápidos**: Botões de acesso rápido para guardar valores (`+ R$ 25` e `+ R$ 100`).
- **Simulação de Retirada**: Botão para efetuar saques (`- R$ 25`) com proteção contra saldo negativo.
- **Feedback Visual de Meta Atingida**: Mudança automática da cor do saldo e da barra de progresso para azul quando a meta é alcançada, exibindo também a mensagem `"Meta alcançada!"`.
- **Reiniciar Cofrinho**: Opção para zerar o saldo acumulado a qualquer momento.

---

## Como Executar o Projeto

1. **Clonar o Repositório**:
   ```bash
   git clone https://github.com/ssophialara/cofrinho-digital-android..git
   ```
2. **Abrir no Android Studio**:
   - Abra o Android Studio e selecione `Open`.
   - Escolha a pasta do projeto clonado (`CofrinhoDigital`).
3. **Executar o Aplicativo**:
   - Aguarde a sincronização do Gradle (Gradle Sync).
   - Selecione um dispositivo virtual (Emulador) ou físico com a depuração USB ativada.
   - Clique em **Run 'app'** (`Shift + F10`).
